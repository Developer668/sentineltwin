# CockroachDB Cloud Managed MCP example

Copy the exact snippet generated by the CockroachDB Cloud Console for your client and cluster. `managed-mcp.example.json` documents the expected remote endpoint and environment placeholders; clients differ in whether they label the transport `http`, `streamable-http`, or infer it from the URL.

1. Configure the cluster's Managed MCP Server in **read-only** mode.
2. Export `COCKROACH_MCP_TOKEN` through the client's secure environment/credential store and `COCKROACH_CLUSTER_ID` from Cloud Console. Never replace placeholders in a committed file.
3. Restrict the identity to the SentinelTwin database/schema and enable/review audit logging.
4. Test with `SELECT`/schema inspection only; do not grant schema or row writes to the judge/operator connection.
5. Rotate/revoke the token after judging and attach only a sanitized audit screenshot to the submission.

The endpoint is `https://cockroachlabs.cloud/mcp`. Authentication/headers may evolve; the Cloud Console's generated config is authoritative for the installed client. Merely adding this example does not justify claiming MCP usage—capture a real read and audit event first.
